# VoxFoundry

VoxFoundry clones **your own voice** from a short recording and uses it to read long voiceover
scripts in English and Hindi. Everything runs **locally** on your machine with the open
[XTTS-v2](https://huggingface.co/coqui/XTTS-v2) model. No audio or text is sent to a cloud
service.

It was built to produce narration for short-form videos without recording every take by hand.
You record yourself once, write a script, and VoxFoundry generates the full voiceover as a WAV file.

> **Use only voices you are authorised to clone.** That means your own voice, or someone who has
> given explicit consent.

---

## How it works

```text
 reference.wav ─┐
 (your voice)   │      ┌────────────────┐     ┌──────────────────────┐     ┌──────────────┐
                ├────▶ │ Text processor │ ──▶ │ XTTS-v2 (local, MPS/ │ ──▶ │  Assembler   │ ──▶ voiceover.wav
 script.txt ────┘      │ parse + chunk  │     │ CPU/CUDA) per chunk  │     │ pauses + WAV │
                       └────────────────┘     └──────────────────────┘     └──────────────┘
```

1. **Reference check.** The reference recording is validated before anything else runs: it
   must exist, decode, contain audible signal, and not be too short.
2. **Voice conditioning.** XTTS-v2 reads up to the first 30 seconds of the reference and turns it
   into a *speaker embedding* and *GPT conditioning latents*, a compact numeric description of
   your timbre, pitch and speaking style. Nothing is trained or fine-tuned: cloning is
   zero-shot, so a new reference takes effect immediately.
3. **Text processing.** The script is split into language segments (`[EN]` / `[HI]`). Very short
   lines are merged, and long lines are chunked under the model's limits (200 characters for
   English, 130 for Hindi) so it doesn't hallucinate or cut off words.
4. **Synthesis.** Each chunk is generated by XTTS-v2 using your voice conditioning (24 kHz mono).
   Generation is seeded (`seed=42`) for reproducibility. Durations that don't fit the text are
   detected and retried.
5. **Assembly.** Chunks are joined with natural pauses: longer after `?` and `...`, and a
   paragraph pause for a blank line. The result is written as 16-bit PCM WAV, and its duration,
   peak and loudness are printed.

The model is loaded once, and Hugging Face runs in **offline mode** unless you explicitly pass
`--allow-download`. After the first download, generation needs no network at all.

## Requirements

- Python **3.12**
- macOS with Apple Silicon (MPS) is the tested setup. CPU works everywhere, and CUDA is supported.
- About 2 GB of disk space for the XTTS-v2 checkpoint
- `ffmpeg` (optional), only for converting recordings to WAV

## Installation

```bash
git clone https://github.com/<your-username>/VoxFoundry.git
cd VoxFoundry

python3.12 -m venv .venv-xtts
source .venv-xtts/bin/activate

pip install -r requirements.txt
pip install -e .            # installs the `voxfoundry` command
```

The first real run must download the model (~1.88 GB) once:

```bash
voxfoundry generate --allow-download --text "Hello." \
    --reference-audio references/final_reference.wav --output output/first.wav
```

## Usage

### 1. Record a reference

Record 15–30 seconds of clear, natural speech in a quiet room, with no music and no other
speakers. Convert it to mono WAV and place it in `references/`:

```bash
ffmpeg -i my_recording.m4a -ar 22050 -ac 1 references/final_reference.wav
```

### 2. Write a script

```text
[EN]
Welcome to VoxFoundry. This short script shows the supported format.

Each line is spoken as one sentence group. A blank line adds a paragraph pause.

[HI]
नमस्ते, यह हिंदी में एक छोटा सा उदाहरण है।
```

- A line containing only `[EN]` or `[HI]` switches the language.
- A blank line adds a paragraph pause.
- Lines shorter than 30 characters merge into the next line of the same language.
- Write numbers as words ("twenty-five thousand") for the most natural reading.

See [examples/sample_script.txt](examples/sample_script.txt).

### 3. Generate

```bash
# From a script file
voxfoundry generate \
    --script examples/sample_script.txt \
    --reference-audio references/final_reference.wav \
    --output output/voiceover.wav

# Quick test from inline text
voxfoundry generate --text "This is a quick test." \
    --reference-audio references/final_reference.wav --output output/test.wav
```

`python -m voxfoundry generate ...` works the same way.

| Option | Purpose |
|---|---|
| `--device mps\|cpu\|cuda` | Inference device (default `mps`). It is never switched silently: if MPS is unavailable, pass `--device cpu` yourself. |
| `--language en\|hi` | Default language for lines before any marker (default `en`). |
| `--max-chars N` | Override the chunk length limit. |
| `--overwrite` | Replace an existing output file. |
| `--cache-dir DIR` | Cache generated chunks, so re-runs after small script edits are fast. |
| `--legacy-clip-cleanup` | Apply the old per-chunk trim, fade and level-match. |
| `--allow-download` | Allow downloading the model checkpoint. |
| `--engine mock` | Test tone instead of speech, for checking the pipeline without the model. |
| `-v` | Verbose logging. |

Exit codes: `0` ok · `1` internal · `2` usage · `3` invalid input · `4` environment/model/device ·
`5` generation failure · `6` not implemented.

## Testing

```bash
python -m pytest                     # unit + integration tests (no model needed, ~3 s)
python -m pytest -m unit
python -m pytest -m real_model -v    # real XTTS-v2 inference; needs the cached checkpoint
```

Real-model tests are skipped unless selected, and they never download. CI
(`.github/workflows/tests.yml`) runs the default suite on every push and pull request.

## Privacy

Voice recordings are biometric data. The repository's [.gitignore](.gitignore) blocks every
common audio and video format, the `references/` and `output/` folders, speaker
embeddings (`.npy`, `.pkl`), model files, logs and `.env` files, so they can't be committed by
accident. Keep a separate backup of your reference recording, because git doesn't store it.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `ModelLoadError ... downloads are disabled` | Run once with `--allow-download`. |
| `DeviceUnavailableError: ... 'mps'` | Use `--device cpu`. |
| `ModuleNotFoundError: six` | `pip install six==1.17.0` (coqui-tts doesn't declare it). |
| `cannot import name 'TransformGetItemToIndex'` | torch is older than 2.6. Reinstall from `requirements.txt`. |
| `Unsupported marker [HOOK]` | Only `[EN]` / `[HI]` markers are supported. |
| Exit code 3, "Output exists" | Choose a new `--output` or pass `--overwrite`. |
| Voice doesn't sound like you | Use a cleaner 15–30 s reference with steady volume and no background noise. |
